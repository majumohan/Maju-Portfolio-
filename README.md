# Maju Mohan — Portfolio

A responsive, premium dark developer portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

1. Replace `public/resume.pdf` with your latest approved resume PDF.
2. Add live demo and source-code URLs to the project cards if you want each card to link to a project.
3. Confirm your experience dates and project descriptions are current.
4. Deploy the project to Vercel or another static hosting provider.

The portfolio content is based on the resume supplied in the conversation. It currently uses the resume's stated `3+ years` and the dates shown there.
